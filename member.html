                개인정보처리방침

                시행일: 2026년 10월 10일

                대한예수교장로회 더행복한교회(이하 ‘교회’)는 성도마당 이용자의 개인정보를 소중히 다루며, 「개인정보 보호법」에 따라 다음과 같이 처리합니다.

                1. 수집하는 항목과 방법

                • 카카오 로그인 시 카카오로부터 받는 정보: 닉네임(필수), 프로필 사진(선택), 카카오계정 이메일(선택)
                • 이용 중 직접 작성하는 정보: 성경 필사 내용, 큐티 묵상 글

                2. 이용 목적

                • 회원 식별과 로그인 유지
                • 성경 필사 진도 저장, 큐티 기록 보관, 묵상 나눔 게시 시 작성자 표시
                • ‘교회 묵상집에 실어도 좋아요’에 동의한 묵상의 묵상집(책) 제작
                • 기도 모임 안에서 기도 여부·연속 기록·응원 표시

                3. 보유 기간

                회원 탈퇴 시 즉시 삭제합니다. 탈퇴는 로그인 후 ‘내 정보 → 회원 탈퇴’에서 직접 할 수 있습니다.

                4. 공개 범위

                큐티 글은 기본적으로 본인만 볼 수 있으며, ‘성도들과 나누기’를 선택한 글만 로그인한 성도에게 이름과 함께 보입니다. ‘함께 쓰는 성경’에 필사한 말씀은 온 교회가 이어 쓸 수 있도록 로그인한 성도에게 작성자 이름과 함께 보입니다. ‘홈페이지에 공개’를 선택한 큐티는 로그인하지 않은 방문자도 작성자 이름과 함께 볼 수 있습니다. 기도 체크와 기도 제목은 같은 기도 모임 안에서만 보입니다.

                4-1. 만 14세 미만 아동

                만 14세 미만 아동은 법정대리인(부모님)의 동의를 받은 뒤 이용할 수 있습니다. 동의 없이 가입한 사실을 알게 되면 해당 정보를 지체 없이 삭제합니다.

                5. 처리 위탁 및 국외 이전

                교회는 회원 정보와 글을 안전하게 보관하기 위해 데이터 저장을 위탁합니다.

                • 수탁자: Supabase Inc. (미국) — 데이터는 Amazon Web Services 서울 리전(대한민국)에 저장됩니다.
                • 이전 항목: 위 1항의 정보 / 이전 시기: 로그인 및 글 저장 시 네트워크를 통해 전송 / 보유 기간: 회원 탈퇴 시까지

                6. 이용자의 권리

                이용자는 언제든지 자신의 글을 수정·삭제하고, 표시 이름을 바꾸거나 탈퇴할 수 있습니다. 카카오 계정 연결은 카카오톡 설정 → 카카오계정 → 연결된 서비스 관리에서도 끊을 수 있습니다.
